# Система управления умного океанариума

## Кто пользуется

- **Служебное окно** — технический персонал: протечки, свет, вентиляция.
- **Окно ветеринаров** — те, кто следит за животными: температура, загрязнённость и кислотность воды, фильтрация.

## Датчики

1. **Датчик протечки** — измерение наличия воды на полу в помещениях, перекрытие воды.
2. **Датчик температуры** — измерение температуры воздуха, контроль микроклимата и среды аквариумов.
3. **Датчик света** — контроль освещения в залах.
4. **Датчик вентиляции** — контроль влажности.
5. **Датчик загрязнённости воды** — мутность воды.
6. **Датчик кислотности воды** — pH воды.
7. **Фильтр** — режим фильтрации: умеренная или усиленная.

## Сценарии

1. Датчик протечки = 1 → отключить воду → уведомление о протечке → датчик вентиляции = 1.
2. Загрязнённость выше нормы → усилить фильтрацию → уведомление ветеринарам.
3. Кислотность ниже нормы → усилить фильтрацию → уведомление ветеринарам.
4. Кислотность выше нормы → усилить фильтрацию → уведомление ветеринарам.
5. Температура > нормы → включить охлаждение → уведомление.
6. Температура < нормы → включить подогрев → уведомление.
7. Если вечер → датчик света = 75.
8. Если ночь → датчик света = 10.
9. Если день → датчик света = 40.
